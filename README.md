# RIDE — UI/UX Design System

A premium mobile ride-hailing UI/UX concept focused on a consistent design system, reusable components, responsive behavior, interaction states, and a complete ride-booking flow.

## Project Overview

**RIDE.** is a conceptual ride-hailing product designed around a clean black, off-white, and lime visual language.

The project demonstrates how a scalable design system can support a real-world booking experience from destination search through ride completion.

## Design System

- Color palette and semantic colors
- Typography scale
- 4px-based spacing system
- Mobile grid and layout guides
- Border-radius and shadow tokens
- Buttons and interaction components
- Inputs and location cards
- Ride cards and driver cards
- Fare cards
- Tags/chips
- Map controls
- Navigation and status indicators

## Key Screens

1. Home / Map
2. Destination Search
3. Ride Selection
4. Driver Tracking
5. Ride Summary / Payment

## States & Responsive

- Default
- Hover
- Active
- Selected
- Loading
- Disabled
- Searching
- Driver Assigned
- Ride in Progress
- Completed
- Cancelled

Responsive layouts were explored for:

- 320 × 693
- 390 × 844
- 430 × 932
